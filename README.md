A 3D open-world crime game set in a sun-soaked coastal city, built with Three.js and Anime.js. You are a getaway driver in debt to a fixer, hunted by a detective's five-star police response across story missions — steal cars, outrun roadblocks under the helicopter beam, shoot your way out, and spend your cash in the garage. Drive, fight, and escape while the wanted stars, the police radio and the mission clock run as one system. Every vehicle is built in code as a real car: shaped bodywork, glass cabin, detailed wheels, glowing lights — and the coastal boulevard chase is denser than ever: beach, palms, traffic, neon, lit windows.

## Run it

```sh
node serve.ts
```
